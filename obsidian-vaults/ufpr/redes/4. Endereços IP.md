Endereços iP

# IPv4
- 3 classes que determinam a quantidade de bytes para:
- **NET-ID**: rede
- **HOST-ID**: máquina da rede
##### Classe A
- Poucas redes e muito hosts
- Inicia com 0
- NET-ID 1 BYTE e HOST-ID 3 BYTES
##### CLASSE B
- "Intermediária"
- Inicia com 10
- NET-ID 2 BYTES e HOST-ID 2 BYTES
##### Classe C
- Muitas redes e poucos hosts
- Inicia com 110
- NET-ID 3 BYTES e HOST-ID 1 BYTE
##### Classe D
- Classe para Multicast
- Definir grupos de destinatários
- Endereço IP multicast (grupo) além do unicast (host)
##### Classe E
- Endereços para uso futuro
## Comunicação
1. UniCast - um para um
2. BroadCast - um para todos
3. MultiCast - um para grupo
4. AnyCast - um para membro do grupo
### Tipos de máquinas IP
- Host: máquina conectada a uma única rede
- Roteador: máquina conectada a duas ou mais redes
	- Geralmente conecta redes
	- Camada de rede
### Endereços especiais
- **HostID zerado (000...)** -> própria rede
- **HostID com 1 (255)** -> broadcast (um para todos)
	- Destino para todos da rede
	- Geralmente desabilitado por questões de segurança
- **Loopback: 127.0.0.1** -> o próprio host
	- Testes de protocolo

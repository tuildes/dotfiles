### Tamanho do Datagrama
Número de bytes (8 bits) total do pacote iP
IP até 2^16
Pacotes IP de até 64k bytes
- Quadro Ethernet até 1500 bytes (MTU da Ethernet)
- MTU: Maximum Transfer Unit
#### Fragmentação do IP
Pacote IP é quebrado em mútiplos fragmentos para serem transmitidos
1 fragmento IP vira mini pacotes IP
### Campo: identificador (16b)
- Identifica o fragmento
- 3 flags: 
	- More (1 para todos os fragmentos menos no último)
	- Dont fragment -> proibido fragmentar
### Campo: Deslocamento (offset)
O quanto está deslocado, por exemplo:
1. Fragmento = 0 bytes
2. Fragmento = 1500 bytes
Cuidado com o tamanho do header
3. Fragmento = 0 (tamanho total)
4. Fragmento = 1480 bytes (header novo de 20 bytes)

Fragmentos fora o primeiro
- MTU - 20 bytes por fragmento
- Acrescente 20 bytes de header
	- O primeiro já tem

Remonta o pacote no destino (ponta)

Pode fragmentar o IP muitas vezes
- Fragmentar o fragmento

Feito tudo pelo protocolo IP
- Verifica no roteador - Tamanho do pacote > MTU do Enlace
### Campo: Time To Live (TTL)
- Quantidade de "tempo" que o pacote pode ficar na rede
	- Tempo não é usado - problema de sincronização
- Evitar lOOP
- Conta número de hops (saltos)
- Default: 64 ou 128
### Campo: Protocolo
- Define o protocolo que gerou o IP
	- Pode ser até o próprio IP
### Campo: CheckSum
- Por ser implementado em software, é mais lento que o hardware
- Checksum calculado apenas sobre o header
- ORIGEM: calcula o checksum e armazena
- DESTINO: recalcula o checksum

Palavras de 16 bits
1. Soma as palavras usando complemento de 1
	1. Se der "vai um", soma +1
2. Tira o complemento do resultado
3. Se fazer a soma + checksum e der 0 então tudo OK
### Campo: Opcionais IP
- Quase sempre desabilitados nos roteadores -> descarte de pacote
- Problemas de segurança
- **Source Route**: Roteamento na origem
- **Recorde Route**: determina a ordem dos roteadores no pacote
- **Timestamp:** grava endereço e o tempo UTC
- Outros...
### Campo: Padding
- Bits de valor zero para o tamanho do header seja múltiplo de 24

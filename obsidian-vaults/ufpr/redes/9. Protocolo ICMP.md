# ICMP: Internet Control Message Protocol
Meio de reportar erros e mensagens de controle

**Situação**: roteador descobre erro no pacote IP, uma mensagem de erro é enviada ao host de origem
- Utiliza-se do IP para transmitir a mensagem ICMP
- Não se gera ICMP para pacotes IP com mensagens ICMP
*Sempre é um protocolo implementado ao lado do IP*
![[datagramaICMP.png]]
### Tipos de mensagem ICMP
1. **Tipo 0**: Echo Request/Reply
	1. Tal do "*PING*"
	2. Verificar se uma resposta chega corretamente (até a camada 3) e todo o roteamento funcionada
	3. Não diz nada sobre os protocolos L4 (transporte) e L7 (aplicação)
2. **Tipo 3**: Destination Unreachable
	1. O desetino está inatingível
	2. Campo código diz o porquê:
		1. 0: rede
		2. 1: host
		3. 2: protocolo
		4. ***3: porta***
		5. 4: fragmentação necessária e dont fragment setado
		6. ...
3. **Tipo 11:** Time Exceeded
	1. Campo TTL chegou a zero (sem hops)
	2. O Comando `traceroute` utiliza-se disto!
		1. Pacotes continuos com TTL = 1 .. até o destino
		2. `***` representam lacunas que não respondem ICMP
			1. Desabilitado por segurança
4. **Tipo 4**: Source Quench
	1. ***Congestionamento de rede***: pacotes descartados em taxa alta
	2. Diminuir a carga de novos pacotes na rede
	3. Não é tão utilizado: feito pelo TCP
5. **Tipo 12**: ICMP Parameter Problem
	1. Outros erros e mensagens não identificadas

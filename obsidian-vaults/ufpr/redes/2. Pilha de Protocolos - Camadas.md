# Pilha de Protocolos - OSI
## Camada física (nível 01)
- Representação do bit no meio de transmissão
- **Define como é o meio de comunicação e o valor do BIT**
- O que é 1 e o que é 0 no meio da REDE
## Camada de Enlace (nível 02)
- Link
- Data Link Layer
- **Conecta duas máquinas diretamente (origem e destino)**
- **Transmite strings** de bits de forma eficiente e confiável
	- Protocolos de janela deslizante
	- Confiabilidade por CÓDIGOS DE DETECÇÃO DE ERROS

Redes locais:
- Conecta múltiplas máquinas
- **Protocolo de Controle de Acesso ao Meio (MAC - Medium Access Control)**![[broadcast.png]]
## Camada de Rede (nível 03)
- Comunicação diretamente na rede
- Roteamento
- Como definir um caminho dentro da rede?
## Camada de Transporte (nível 04)
- Interface da borda da rede
- Entrega os dados para serem transportados aos destinos
- Feito nas bordas e não nos roteadores
- **Transmissão de dados fim-a-fim (end-to-end)**
- Confiabilidade: Garantir que os pacotes estão corretos
- Eficiência: Taxa de transmissão
## Camada de Sessão (nível 05)

> [!DANGER]
> Não implementada na internet

- "Diálogo" entre origem e destino
- Permite CheckPoints dos pacotes
	- Em caso de perdas, só retransmite o faltante
- Não implementado na internet
	- Deixado para cada serviço em SO fazer isto
	- Feito na própria aplicação
## Camada de Apresentação (nível 06)

> [!DANGER]
> Não implementada na internet

- Definir o que os dados (bits e bytes) são (sintaxe)
	- Tipo de dado, linguagem...
	- Hoje feito na camada de aplicação
- Fazer segurança
- Compressão de dados
## Camada de Aplicação (nível 07)
Web (HTTP), transferência de arquivo, Terminal Virtual Remoto, ...
Como o pacote é visto pelo sistema
Provem serviços para aplicações

# Protocolos TCP/IP
- Modelo mais utilizado atualmente
- Família de protocolos
- Principais:
	- **IP**: Internet protocol -> camada de rede
	- **TCP**: Transmission Control Protocol -> camada de transporte
- Pilha de protocolos
	- Enlace (1)
	- Rede (2)
	- Transporte (3)
	- Aplicação (4)
- Padrão da Internet - RFC
	- RFC-791 por exemplo define o IPv4

### Exemplo
1. O browser faz o protocolo HTTP que constrói um PDU (Protocol Data Unit)
	- Protocolo de Aplicação chama o protocolo de transporte que faz um segmento com o PDU
	- Feito em S.O.
2. TCP chama o protocolo de REDE que faz um pacote IP englobando tudo
	- Feito pelo S.O.
3. Protocolo de Enlace é chamado para fazer um quadro/frame ethernet
	- Feito em HARDWARE (placa)

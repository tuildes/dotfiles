## Conceito: Padrão (Standard)
- Especificação pública
- Disponível para todos
- **Exemplo**: padrão da placa Ethernet
- Publicado por uma **organização respeitada**
### ISO: International Standards Organization
- Publica diversos padrões
- **Modelo OSI (Open System Interconnection)**
	- Substituído parcialmente pelo padrão da internet (Arpanet) e o desenvolvimento dos protocolos TCP/IP
	- 1990: mundo adota a Internet
	- Utilizado para estudo
- No Brasil, a ABNT é a versão pt-br
### Protocolos
- **Conjunto de regras**
- Definem como os computadores se comunicam (REDES)
- **Para a comunicação universal -> protocolos padronizados**

Organização em camadas
- Protocolo único para cada tarefa
- Protocolos interagem entre si
- Conjunto permite a comunicação entre os computadores
	- **Transmissão da mensagem**
- Pilha de protocolos OSI (Open System Internconnection)
	1. **Física** - BIT a BIT
	2. **Enlace** - STRING entre 2 máquinas diretamente
	3. **Rede** - Roteamento
	4. **Transporte**
	5. ~~**Sessão** - Sistema de CHECKPOINT
	6. ~~**Apresentação** - Tratamento dos dados
	7. **Aplicação**
- Pilha de protocolos TCP/IP
	1. Físico
	2. Enlace
	3. Rede
	4. Transporte
	5. Aplicação
# Tecnologias de rede
- Duas grandes famílias: LAN & WAN
	- **LAN: Local Area Network** (REDE LOCAL)
		- Espaço privado
		- Outras famílias: PAN e MAN
		- **Comunicação baseada em broadcast (1 para todos)**
			- Passa por todos (mas só é pego pelo destino)
	- **WAN: Wide Area Network** (REDE DE LONGA DISTÂNCIA)
		- Espaço público
		- Só com permissão oficial para transmitir dados
		- **Comunicação ponto-a-ponto (origem e destino)**
			- Similar a rede telefônica tradicional -> comutação de circuitos

Internet: **Comutação de Pacotes**
- Unidade de dados: PACOTE
- Vai para uma fila e é transmitida
- Covergência de redes: ALTUALMENTE TUDO É IP

Qualidade de Serviços (QoS)
- Voice Over IP (VoIP)
- Não poder demorar mais que 50ms

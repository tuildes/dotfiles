## Quadro Ethernet
Família de redes

Header, PayLoad e Trailer![[ethernet.png]]
**Preâmbulo (8 bytes)**
- 10101011 representando que há um quadro sendo transmitido
- Ultimo bit representa Start Frame Delimiter
- Meio escuta para ver se há uma transmissão

**Endereço Ethernet (6 bytes)**
- Endereço físico da placa
- MAC address
	- Protocolo de acesso ao meio
	- Era para ser único no mundo
- Rede baseada em broadcast
	- Todos recebem os pacotes
	- Utiliza o MAC para comparar se a máquina é o destino

No fim, o pacote IP é extraído do quadro e enviado ao IP

**Tipo (2 bytes)**
- Identifica o protocolo para o payload
- Geralmente é o IP

**Payload (46 ~ 1500 bytes)**
- Carrega os pacotes (como o do IP)
- Número máximo de dados é 1500 bytes

**Trailer ou CheckSum (4B)**
- Detecção de erros
	- Bits trocados
- Utiliza o código CRC (muito poderoso)
### Protocolo MAC Ethernet
- Máquinas escutam o meio - Carrier Sense
	- A mesma frequência é escutada
- Protocolo CSMA/CD 1-persistente
	- Se a máquina quer transmitir:
		1. Escuta o meio
		2. Esta livre? Transmite
			1. Com 1.00 de chance (1-persistente)
			2. Outro: p-persis. (p% chance)
			3. Outro: não-persis. (não tenta e da intervalo)
		3. Se não, espera.
		4. Se tiver colisão, interrompe a transmissão (CD)
		5. Tenta novamente por meio do sorteio do intervalo do tempo
			1. 1, 2, 4, 8, 16, ... (número máximo de sorteio) a cada colisão
			2. Na 2^16 desiste
			3. **Ou seja, rede probabilística**

### Redes probabilísticas
- A Ethernet é, pode acontecer de não transmitir um pacote
- Rede industriais não são probabilísticas
- Exemplo: Token Bus
	- Lógica de anel
	- Complexo e pesado de variáveis
- Exemplo: Token Ring
	- Enlaces ponto a ponto
	- Ou seja sem colisão
	- Baseado em broadcast
	- Token centralizado

Internet é uma rede virtual feita por software
- Comunicação universal
- Implementa a família TCP/IP

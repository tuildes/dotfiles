# O que é interface
É a comunicação entre o que você quer e o usuário -> interação
O que faz a interação entre duas coisas (tecnologias, usuários e entre outros)

Quase sempre alinhado a **interface gráfica - GUI**
- Interface é o meio para usar tecnologias e fazer algo
- Plano de contato entre o usuário e a tecnologia

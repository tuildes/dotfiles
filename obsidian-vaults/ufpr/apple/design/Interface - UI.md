# O que é interface
É a comunicação entre o que você quer e o usuário -> interação
O que faz a interação entre duas coisas (tecnologias, usuários e entre outros)

Quase sempre alinhado a **interface gráfica - GUI**
- Interface é o meio para usar tecnologias e fazer algo
- Plano de contato entre o usuário e a tecnologia
## Ser bom
1. Depende da informação
2. Não é necessariamente bonito
	1. Patterns
	2. Affordance
	3. Reação emocional
3. Deve ser ótimo para o seu uso -ls> usabilidade
4. Boa arquitetura
## Usabilidade
Fácil para o usuário usar -> **user friendly**
Interface mais fácil de usar/trabalhar

Eficiência do uso do usuário
Pode ser metrificada (erros, análise heurística, tempo)
- Facilidade de uso, fazer algo, consistência
- Sistema que não precisa "pensar" tanto para fazer algo
- O usuário faz o que acha que é e funciona
	"Não me faça pensar"
